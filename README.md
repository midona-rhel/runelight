# Lumina

Lighting-focused GPU renderer for RuneLite. OpenGL 3.3 core / macOS 4.1, so it runs on Windows, macOS and Linux.

Built on RuneLite's GPU plugin (1.13.4). Shading data (area colours, tile and model overrides) comes from 117 HD.

## Run

```
./gradlew run
```

or run `LuminaPluginTest` (src/test) with the project root as working directory. Turn off the GPU and 117 HD plugins.
