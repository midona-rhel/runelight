# Lumina weather and climate design (from the 2026-10-29 research; to be implemented after shadows)

Old system: 25 patterns x 16 biomes x 4 seasons odds table (weather_types.json, weather_climate.json), ~30 knobs per pattern; the odds table and the seasonal/near-duplicate patterns were the "nonsensical" part. Keep: the forecast as a pure function of (slot, climate) (8 game-hour slots, Markov chain, restarted every 12 slots), the world-anchored WeatherField (16-tile cells, 33x33 window, 5-tap blur, ~80-tile ramps, player value = field sample at focus), the easing constants, the lightning caster swap, instanced particles with a top-down shelter map.

8 patterns: CLEAR, PARTLY_CLOUDY, OVERCAST, RAIN (intensity 0.3-0.7 per slot), STORM (rain 1.0 + lightning), FOG (freezing variant by temperature), SNOW (intensity scalar), SANDSTORM (desert only; own fog colour [1.3,1.0,.65]*horizon luma, warmth +.8, haze .8, sun -.35; sand streaks via the snow pipeline). Fog colour baseline = sky horizon; density = climate baseline (dawn/night mist curve) x pattern multiplier.

Climates (weights per slot): Temperate 30/30/15/15/3/7/winter 5; Wilderness 0 clear, 0 partly, 45 overcast, 20 rain, 25 storm, 10 fog (+ permanent sat -.15, sun -.2); Morytania 0 clear, 5 pc, 40 ovc, 25 rain, 8 storm, 22 fog, damp fog x1.4; Desert 60 clear, 20 pc, 3 ovc, 15 sandstorm; Arctic/Fremennik snow 35, freezing fog, always below 0 C, permanent snow cover; Tirannwn/forests fog x1.1; Kourend/Zeah swamps fog x1.3, Lovakengj ash = area fog tint not weather; Tropical short violent storms; Underground NO_SKY.

Module com.midonarhel.lumina.weather: data patterns.json, climates.json, climate_regions.json (layer stack of tile rects + Area names); ClimateMap, Forecast, WeatherField (~12 channels, one RGBA8 texture pair), WeatherState -> SkyModifiers + FogAtmosphere {colour, density x, height x}; WeatherSource plugged into SkySource.fill in place of SkyModifiers.NEUTRAL; later consumers (shadows' lightning caster, leaves/wind, particles, wetness) read WeatherState only. Particles: instanced quads, no vertex buffer, world-anchored layer boxes, shelter map redrawn on movement; budget <= 0.5 ms at 1080p; mind the 16-sampler limit.

Order: (1) ClimateMap + regions + dev overlay; (2) Forecast + pattern data + tests (Wilderness never clear, sandstorm desert-only); (3) WeatherField + WeatherState feeding sky/fog + Force-weather dev setting; (4) lightning as sky/sun modifier; (5) particles + occlusion map; (6) wetness/snow cover; (7) wind to leaves; (8) lightning caster swap.
